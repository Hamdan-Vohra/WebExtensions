<h1 align="center">Web Extensions</h1>

<h2>📌 Overview</h2>

<p style="font-size:16px;">
Web extensions are lightweight software programs that enhance the functionality of web browsers. 
They allow developers to extend browser capabilities, modify the user interface, 
and provide a more personalized browsing experience for users. 
By leveraging standard web technologies such as <b>HTML, CSS, and JavaScript</b>, 
extensions integrate seamlessly into browsers like <b>Chrome, Firefox, Edge, and Safari</b>.
</p>

---

<h2>🌍 Why Web Extensions?</h2>

<ul style="font-size:15px;">
  <li><b>Cross-browser support</b> → Write once, use everywhere.</li>
  <li><b>Lightweight & Portable</b> → Easy to install, quick to use.</li>
  <li><b>Wide use cases</b> → From ad blockers to productivity tools.</li>
  <li><b>Customizable</b> → Tailor your browsing experience.</li>
</ul>

<p style="font-size:15px;">
With the right permissions, extensions can:
</p>

<ul style="font-size:15px;">
  <li>Interact with web pages</li>
  <li>Capture and process data</li>
  <li>Communicate with external services</li>
</ul>

---

<h2>⚡ Getting Started</h2>

<h3>🔹 Installation</h3>

```bash
git clone https://github.com/Hamdan-Vohra/WebExtensions.git
cd WebExtensions

<h3>🔹 Load in Chrome</h3>
<ol style="font-size:15px;">
  <li>Open <b>Chrome</b> and go to <code>chrome://extensions/</code></li>
  <li>Enable <b>Developer mode</b> (top right)</li>
  <li>Click <b>Load unpacked</b> and select the project folder</li>
  <li>Extension will appear in your list 🎉</li>
</ol>

<h3>🔹 Load in Firefox</h3>
<ol style="font-size:15px;">
  <li>Open <b>Firefox</b> and go to <code>about:debugging#/runtime/this-firefox</code></li>
  <li>Click <b>Load Temporary Add-on</b></li>
  <li>Select the <code>manifest.json</code> file</li>
  <li>Extension will stay active until Firefox is closed</li>
</ol>

<h3>🔹 Usage</h3>
<ul style="font-size:15px;">
  <li>Click on the extension icon in the toolbar</li>
  <li>Access its features directly</li>
  <li>(Optional) Customize settings from the options page</li>
</ul>
```
